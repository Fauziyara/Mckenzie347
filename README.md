# Aperture

A real-time DEX pair scanner built on Arc Network.

## Features

- **Explore** — Browse all DEX pairs on Arc testnet
- **Pulse** — Real-time swap feed and market activity
- **Tracker** — Search tokens and pairs by address or symbol
- **Portfolio** — Track your wallet balance and transactions
- **Earn** — Stake LP tokens and farm rewards
- **Swap** — On-chain token swaps via Presto DEX
- **Tools** — Watchlist to monitor your favorite pairs

## Tech Stack

- **Next.js 16** — App Router, Server Components
- **Tailwind CSS v4** — Dark/light theme
- **Reown AppKit + wagmi** — Wallet connection
- **SQLite** — Local indexer for pairs and swaps
- **Arc Network** — Layer 2 infrastructure (testnet)

## Getting Started

```bash
npm install
npm run build
npm start
```
